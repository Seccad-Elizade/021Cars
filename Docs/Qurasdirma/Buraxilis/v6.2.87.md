# 🏷️ v6.2.87 — Maya sütunları (əsas yenilik)

**İstifadəçi tələbi:** «Birinci ay mayadan 300 ₼ ödənilibsə — **300 ₼ ödənilib**
göstərilməlidir, maya dəyişilib yox ✗. Fərqlər avtomatik göstərilməlidir.»

**Səbəb:** az ödəniş olanda «ƏSAS BORC (maya)» sütununda plan yerinə faktiki
(azaldılmış) rəqəm yazılırdı ✗ → sütun hər ödənişdə «dəyişirdi» ✗

**İndi:**
- ✅ **«🏷️ ƏSAS BORC (maya)» = PLAN** — heç vaxt dəyişmir ✗
- ✅ **YENİ «🏷️ MAYADAN ÖDƏNİLİB»** — REAL ödənişin maya (kök) payı ✓
  (altında «mənfəət X ₼» — tərəfdaşlar arasında bölünən hissə ✓)
- ✅ **YENİ «📊 MAYADA FƏRQ»** — avtomatik: `+` yaşıl = çox ✓ · `−` qırmızı = az ✗ · «plan üzrə» boz ✓
- ✅ Sətir üzərinə siçan → tam izah: plan maya · faktiki maya · fərq · mənfəət · ödənilən ✓
- ✅ **Cədvəlin yekunu**: `🏷️ Maya: plan … · faktiki … · fərq … · faktiki mənfəət …`
- ✅ **PDF hesabatında** da eyni sütunlar + YEKUN sətri ✓
- ✅ **Öz-özünü yoxlama**: `Σ faktiki maya == Ödənilmiş KÖK` ✓ (fərq olsa loqa xəbərdarlıq ✓)

**Düstur** — «Maya ödənilib» və tərəfdaş bölgüsü ilə **tam eyni** ✓:

```
maya payı = ödəniş × (KÖK ÷ kreditin qiyməti) + plandan artıq hissə
mənfəət   = ödəniş − maya payı        ← tərəfdaş bölgüsünün bazası ✓
fərq      = faktiki maya − plan maya  ← avtomatik ✓
```
