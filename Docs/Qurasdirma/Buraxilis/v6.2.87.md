## 021Cars v6.2.87 — Ödəniş qrafikində FAKTİKİ MAYA + AVTOMATİK FƏRQ

### 🏷️ Əsas düzəliş — «maya dəyişilib» problemi HƏLL OLUNDU ✓✓✓

**İstifadəçi:** «Kredit ödəniş qrafikində birinci ay mayadan 300 ₼ ödənilibsə,
**300 ₼ ödənilib** göstərilməlidir — maya dəyişilib yox ✗. Fərqlər avtomatik
göstərilməlidir, hər şey professional olmalıdır.»

**Səbəb:** az ödəniş olanda «ƏSAS BORC (maya)» sütununda **plan yerinə faktiki
(azaldılmış) rəqəm** yazılırdı ✗ → sütun hər ödənişdə «dəyişirdi» ✗✓✓

**İndi:**
- ✅ **«🏷️ ƏSAS BORC (maya)» = PLAN** — heç vaxt dəyişmir ✗ (aylıq plan maya ✓)
- ✅ **YENİ «🏷️ MAYADAN ÖDƏNİLİB»** — REAL ödənişin maya (kök) payı ✓
  (altında «mənfəət X ₼» — tərəfdaşlar arasında bölünən hissə ✓)
- ✅ **YENİ «📊 MAYADA FƏRQ»** — avtomatik: `+` yaşıl = plandan çox ✓ · `−` qırmızı = az ✗ · «plan üzrə» boz ✓
- ✅ Sətir üzərinə siçan → **tam izah**: plan maya · faktiki maya · fərq · faktiki mənfəət · ödənilən ✓
- ✅ **Cədvəlin yekunu** əlavə olundu: `🏷️ Maya: plan … · faktiki … · fərq … · faktiki mənfəət …`

### 🔢 Düstur — hər yerdə EYNİ ✓ (iki yerdə fərqli rəqəm çıxmır ✗)

Maya payı `<c>Credit.OdenisKokPayi</c>` ilə hesablanır — yəni
**«Kreditlər → Maya ödənilib»** və **tərəfdaş bölgüsünün bazası** ilə **tam eyni** ✓✓✓

```
maya payı   = ödəniş × (KÖK ÷ kreditin qiyməti)      ← plan hissəsi
            + plandan artıq hissə (tamamilə mayaya ✓)
mənfəət     = ödəniş − maya payı                     ← tərəfdaş bölgüsünün bazası ✓
fərq        = faktiki maya − plan maya               ← avtomatik ✓
```

| 2 | 1 250,00 | 1 250,00 | plan üzrə ✓ | 1 500,00 | 250,00 |
